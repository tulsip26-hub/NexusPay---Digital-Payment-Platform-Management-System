# NexusPay – Digital Payment Platform Management System

## 📌 Project Overview
NexusPay is a SQL-based Digital Payment Platform Management System designed to simulate a real-world fintech application. The project manages customer accounts, digital wallets, bank accounts, transactions, loans, insurance, rewards, and fraud detection using a normalized relational database.

---

## 🎯 Objective
To design an efficient and scalable database system for a fintech platform that ensures secure transaction management, maintains data integrity, and supports business reporting.

---

## 🛠️ Tech Stack
- SQL (MySQL)
- Relational Database Management System (RDBMS)
- ER Diagram
- Database Normalization (3NF)

---

## ✨ Features
- Customer Registration & Profile Management
- Digital Wallet Management
- Bank Account Integration
- Money Transfer & Transaction History
- Loan & EMI Management
- Insurance Policy Management
- Rewards & Cashback Tracking
- Fraud Detection & Risk Monitoring
- Customer Feedback Analysis
